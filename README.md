### 슬라이드 편집 원칙

- **원문 전체 보존:** `source/skin/ORIGINAL_PresentationScript_EN-KO_v1.0.md`에 첨부 대본을 보관했습니다. 원문의 모든 발표 슬라이드와 EN/KO 발화문 291쌍을 `sentences` 데이터에 **문구 수정 없이** 연결했습니다.
- **Step 1 — 발표 청크 직독직해:** 각 발화를 기본 청크로 다루되, 영문·국문 모두 쉼표로 구획된 절이 명확히 대응하는 경우에 한해 소구간으로 분리했습니다. 신규 384개 학습 청크는 **학습 편집 구조**이며, 분절된 문장은 별도의 검증 번역이 아닙니다.
- **Step 2 — 영한 문장 1:1 낭독:** 영어 원문 한 발화 → 해당 한국어 원문 확인, 낭독 또는 번역 숨기기.
- **Step 3 — 발표 연습:** 영어 원문 낭독, 한국어를 보고 영어로 말하기, 발표 타이머(WPM 기록), 퀴즈와 문장 복습.
- **빠른 목차:** 학습 목록에서 `Skin 발표 74` 필터 → 제0부~제11부 및 표지·마무리별로 펼쳐 슬라이드를 바로 선택.
- **원본 발표 시간:** 각 편의 학습 주제 메타정보에 원본 슬라이드의 발표 타임라인을 기록했습니다.
- **문서 수정판:** `Skin_Surface_Contamination_Chunk_Reading_Studio_74_Slides_EN_KO.md`는 74편을 하나로 합친 편집형 마크다운입니다. 슬라이드별 Markdown도 `source/skin/S01_...md` 등으로 분리했습니다.

**자료의 내용과 한계:** 원본에 기재된 수치·국가별 규정·표준 문구·인용이 최신이거나 기술적으로 타당한지를 독립 조사한 것은 아닙니다. 이는 **사용자 제공 발표 대본을 영어 학습 형태로 재구성**한 결과입니다. 방사선방호 실무 결정이나 공식 인허가·선량기록에는 원문 1차 자료와 현행 법령을 별도로 확인해야 합니다.

## 2. 연속 듣기

대시보드와 학습 목록의 **연속 듣기** 창에서 다음 재생목록을 선택할 수 있습니다.

- Core 30편 / University 30편 / Domain 18편 / Conference 8편
- Variety 1권 30편 / 2권 30편 / Variety 전체 60편
- 기존 Core+University 60편
- **Skin Presentation 발표 전체 74편 (신규)**
- **전체 220편 (신규)**

선택한 트랙은 편별로 자동 이동해 재생합니다. `청크/표현별` 또는 `문장별`을 선택할 수 있으며, **영어 후 한국어 번역 듣기**, **현재 항목 중앙 스크롤**을 별도로 켜고 끌 수 있습니다. **0.5~2.5배속(0.1 단위)**으로 재생 중 변경하면 해당 낭독 항목에서 다시 시작합니다.

재생창은 모바일에서 작은 고정 막대로 표시되며, 진행률·이전 편·일시정지·다음 편·정지·속도·접기/펼치기를 제공합니다. 마지막 연속 듣기 위치가 로컬 저장소에 보관되어, 중단 시 홈에서 **마지막 위치부터 이어 듣기**를 선택할 수 있습니다. 학습 기록·설정은 기존 v1.x와 **동일한 저장 키**를 사용하므로 단순 파일 교체 시 유지됩니다(브라우저 데이터를 초기화하지 않는 경우).

### 안정성·환경 한계

v1.3에서 도입한 짧은 문장 분할, `interrupted`/`canceled` 오류 재시도, watchdog, 간헐적 keep-alive, 과거 이벤트 방지 토큰, 탭 복귀 복구를 유지했습니다. 그러나 **iOS/Android 화면 잠금·배터리 최적화·브라우저 백그라운드 제한**까지 무중단을 보장하지는 못합니다. 장시간 화면을 끄고 듣는 용도라면 **사전 생성 MP3 기반 HTML5 Audio 플레이어**가 더 적합합니다.

## 3. 읽기 설정

`설정` 메뉴에서 **영어 글자 크기 5~50px**, **한국어 글자 크기 5~50px**, **줄간격 0.1~5.0배**를 슬라이더/숫자 입력으로 조절합니다. 다크 모드, 번역 표시, 음성 속도, 복습 문장, 진도, 메모, 학습통계, JSON 백업 및 복원을 그대로 지원합니다.

## 4. GitHub Pages 배포

1. 압축을 풀어 `index.html`, `app.js`, `content.js`, `styles.css`, `service-worker.js`, `assets/`, `source/` 등 **ZIP 최상위의 내용물**을 기존 GitHub Pages 저장소의 루트에 복사합니다.
2. GitHub 저장소 → `Settings → Pages → Deploy from a branch → main / (root)` 설정을 확인합니다.
3. 공개 URL로 접속하고 화면 접근 비밀번호 **`redpass`**를 입력합니다.
4. 이전 버전이 나오면 강력 새로고침을 사용합니다. v1.4에서는 캐시 이름 `chunk-reading-studio-offline-v1-4`, CSS/JS 파일 버전 `?v=1.4`로 변경했습니다.
5. Windows 사용자는 `START_WINDOWS.bat`, Mac/Linux에서는 `START_MAC_LINUX.sh`로 간단한 로컬 웹서버를 실행할 수 있습니다.

> **중요:** GitHub Pages의 브라우저 단 비밀번호 검사는 **실제 접근 보안이 아닙니다.** GitHub에 공개된 `content.js`와 `source/`는 비밀번호 없이 열람할 수 있습니다. 공개하면 안 되는 자료는 정적 저장소에 올리지 마세요.

- 낭독 테스트는 **모의 음성합성 엔진**을 이용했습니다. 실제 휴대폰 음성 품질이나 잠금 화면 연속 재생을 검증했다는 의미는 아닙니다.

## 7. 용어

- **청크(Chunk)**: 낭독 및 독해를 위해 나눈 의미·호흡 단위. 이번 발표 트랙은 원문 영한 일치 여부를 우선하므로 문장 단위 청크를 기본으로 사용합니다.
- **TTS (Text-to-Speech)**: 문자열에서 음성을 합성하는 기술.
- **Web Speech API**: 브라우저/운영체제가 제공하는 음성합성 인터페이스.
- **Watchdog**: 재생 엔진이 응답하지 않을 때 재시도하는 감시 로직.
- **PWA**: 웹사이트를 앱과 유사하게 설치하고 일부 리소스를 오프라인으로 보존하는 웹 기술.
- **Bq/cm²**: 단위 면적당 표면 방사능을 나타내는 단위.
- **Smear (도말법)**: 표면을 닦아 시료를 채취하여 오염을 간접 평가하는 절차.
- **MDA/MDC**: 각각 최소검출가능방사능 / 최소검출가능 농도에 해당하는 계측 검출성능 지표(맥락에 따라 정의 및 계산이 달라짐).
