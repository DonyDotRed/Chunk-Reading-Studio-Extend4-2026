# Variety Track · 다양한 장르 낭독 (목차 30편)

지금까지의 낭독 자료는 수필, 학술 에세이, 논문 절처럼 **설명·논증하는 글**이 중심이었습니다. Variety Track은 낭독의 폭을 넓히기 위해 **리듬, 목소리, 호흡이 서로 다른 열 가지 장르**를 모았습니다. 이야기는 인물의 목소리를, 연설은 쉼과 강세를, 시는 운율을, 뉴스는 일정한 속도를, 대화극은 주고받는 타이밍을 연습하게 해 줍니다.

## 원문의 종류

| 표시 | 의미 |
|---|---|
| 오리지널 | 이 교재를 위해 새로 쓴 글 |
| 퍼블릭 도메인 | 저작권 보호 기간이 끝난 역사적 원문 (1929년 이전 발표). 원문을 그대로 싣고, 한국어 번역은 새로 함 |

형식은 이전 트랙과 같습니다(원문 → 1회차 청크 → 2회차 문장 → 낭독 포인트 → 어휘장 → 낭독 기록표). 각 편 앞에 **장르별 낭독 팁**을 넣었습니다.

## 장르별 낭독법 요약

| 장르 | 연습 초점 | 권장 속도 |
|---|---|---|
| 이야기 | 서술과 대사의 목소리 구분, 장면 전환의 쉼 | 120–150 WPM |
| 명연설 | 대시와 쉼표의 쉼, 반복 구문의 강세, 절정으로 갈수록 힘 | 100–130 WPM |
| 대중 과학 | 핵심 용어 또박또박, 대조어 강세 | 130–150 WPM |
| 뉴스 | 일정한 속도, 숫자·고유명사 명확히 | 150–170 WPM |
| 편지·일기 | 1인칭의 친밀한 어조, 감정의 변화 | 120–140 WPM |
| 시 | 행 끝의 쉼, 운율과 각운 | 80–110 WPM |
| 대화극 | 주고받는 타이밍, 인물별 목소리 | 대사마다 다름 |
| 강연 | 청중에게 말하듯, 질문과 쉼 | 130–150 WPM |
| 과학 고전 | 긴 문장의 호흡 나누기, 19세기 문체 | 100–130 WPM |
| 여행 글 | 감각 묘사의 생생함 | 120–150 WPM |

권장 속도는 대략적인 기준입니다. 처음에는 느리게 정확히 읽고, 회차를 거듭하며 이 범위에 가까워지면 충분합니다.
